# Welcome to Micro-SaaS Documentation 🚀

Your complete guide to building and deploying a professional SaaS platform.

## Quick Start

Get up and running in **5 minutes**:

```bash
# 1. Clone the project
git clone https://github.com/sahdesings-1998/MICRO_SAAS.git
cd MICRO_SAAS

# 2. Install & setup server
cd server
pnpm install

# 3. Install & setup client (new terminal)
cd client
pnpm install

# 4. Start both and visit http://localhost:5173
```
