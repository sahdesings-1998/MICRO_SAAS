# Guides Introduction

Welcome to the Micro-SaaS Guides section. Here you'll find detailed, step-by-step instructions for common tasks and configurations.

## Available Guides

### 1. **Authentication Guide**
Learn how to implement and manage user authentication in your Micro-SaaS application.
- User registration and login
- JWT token management
- Password reset and recovery
- Two-factor authentication (optional)

→ [Go to Authentication Guide](./authentication)

### 2. **Database Guide**
Understand how to work with the database layer of Micro-SaaS.
- Database schema overview
- Creating and managing models
- Running migrations
- Seeding data
- Backup and restore procedures

→ [Go to Database Guide](./database)

### 3. **Deployment Guide**
Deploy your Micro-SaaS application to production.
- Environment preparation
- Build optimization
- Deployment to Vercel, Heroku, AWS, etc.
- CI/CD setup
- Monitoring and logging

→ [Go to Deployment Guide](./deployment)

## Guide Topics

Each guide covers:

- **Step-by-Step Instructions** - How to do it
- **Code Examples** - Practical implementations
- **Best Practices** - Tips and tricks
